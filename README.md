# Практика useEffect

Домашняя работа: 10 интерактивных примеров на React + TypeScript + Vite.

## Запуск

```sh
bun install
bun run dev
```

Открой адрес, который выведет Vite (обычно http://localhost:5173).
Можно использовать npm: `npm install` и `npm run dev`.

```sh
bun run build   # Проверка TypeScript и сборка
bun run lint    # Проверка кода
bun test        # Проверка учебного API и очистки соединения
bun run preview # Просмотр сборки с учебным API
```

## Где находятся задания

В `src/components/Exercises.tsx` каждый пример оформлен отдельным компонентом:

1. `TitleCounter` — счётчик, обновление document.title и восстановление исходного заголовка.
2. `SavedName` — ленивая инициализация useState из localStorage и сохранение имени через эффект.
3. `WindowSize` — размеры окна, подписка resize и удаление обработчика.
4. `Stopwatch` — старт, пауза и сброс; функциональное обновление и очистка интервала.
5. `MouseTracker` — условная подписка mousemove с очисткой при выключении.
6. `UsersList` — загрузка, успешный ответ, ошибка и отмена через AbortController.
7. `UserProfile` — запрос при изменении userId с отменой и защитой от устаревшего ответа.
8. `DebouncedSearch` — задержка 500 мс, отмена таймера и запроса, пропуск пустой строки.
9. `StatusPolling` — запрос сразу и раз в 10 секунд; запрет перекрывающихся запросов, отмена и пауза.
10. `ChatRoom` — использование собственного хука `src/hooks/useChatRoom.ts`.

`src/lib/connection.ts` содержит условную `createConnection(roomId)` с методами `connect`, `disconnect`, `on`, `off`. Это имитация соединения: первое сообщение приходит после подключения, следующие — каждые 7 секунд. При смене комнаты хук удаляет подписки и отключает старое соединение.

## Учебный API

Реальные HTTP-запросы обрабатывает локальный Vite-плагин в `server/api.ts`. Внешний сервер и ключи не нужны. Он работает в `dev` и `preview`:

- `GET /api/users` — список четырёх пользователей.
- `GET /api/users/:id` — выбранный пользователь. Разная задержка ответов позволяет проверить быстрое переключение.
- `GET /api/search?q=...` — поиск по материалам React.
- `GET /api/status` — состояние учебного сервиса.
- `GET /api/users?fail=true` — намеренная ошибка 503 для демонстрации обработки ошибок.

При отдельной публикации папки `dist` на статическом хостинге нужен собственный сервер для `/api/*`: Vite-плагин в браузерную сборку не входит.

## Как проверить очистку

Кнопка «Скрыть примеры» удаляет компоненты со страницы: исходный заголовок восстанавливается, события отписываются, таймеры останавливаются, запросы отменяются. Фильтры категорий также удаляют скрытые компоненты. Имя сохраняется при повторном появлении и перезагрузке страницы. StrictMode включён, поэтому при разработке React дополнительно проверяет цикл подключения и очистки.
